# AionPulse - releases

Downloads for AionPulse (called AionHPS before 0.3.3), a companion app for Aion 2: your character, Combat Power,
kina, pets, Genus Insight and a healing meter in one window, with an optional overlay over the game. Each release
also has a zip of the app's code: that's only for copies set up from a zip before the installer, so they can update.

**Install:** download `AionPulse-Setup-<version>.exe` (not the zip) from the [latest release](../../releases/latest)
and run it. Windows may say it protected your PC (the app isn't code-signed): click **More info**, then **Run
anyway**. (If it says Smart App Control blocked it, AionPulse can't run while Smart App Control is on.) AionPulse
opens when it's done, and it's on your Desktop and Start menu. It needs [Npcap](https://npcap.com/#download),
installed with the default options; you likely have it already if you use another DPS meter. Then go to character
select and back in once, so your gear, pets and Genus Insight load.

**Have AionHPS installed?** It updates itself to AionPulse: same app, new name, and your data comes along.

**Used AionHPS from a zip before?** Quit it, install, then click **Import from an older copy** on Home and pick your
old AionHPS folder: your Combat Power history, kina and pets come over.

**Updates:** AionPulse downloads new versions by itself; Home offers **Restart to update**, or the update installs
when you quit AionPulse.

**Your data** (character, pets, kina, settings) is kept in `%APPDATA%\AionPulse`, so updates and uninstalls never
touch it.

AionPulse reads a copy of the game's network traffic. It doesn't touch game files or game memory. It's an unofficial
fan tool: use it at your own risk.
