# AionHPS - releases

Downloads for AionHPS, a companion app for Aion 2: your character, Combat Power, kina, pets, Genus Insight and a
healing meter in one window, with an optional overlay over the game. There's no source code here.

Download the latest `AionHPS-<version>.zip` from the [Releases](../../releases/latest) page, unzip it, and follow
`START HERE.txt` inside. It needs Npcap, Python 3.11 and Node.js, installed once.

AionHPS reads a copy of the game's network traffic. It doesn't touch game files or game memory. It's an unofficial
fan tool: use it at your own risk.
